رشيد العربية - تحديث الواجهة الرئيسية
====================================

الهدف:
- جعل index.html هي البوابة الرئيسية وبداخلها تسجيل الدخول.
- الحفاظ على login.html كصفحة دخول مباشرة/احتياطية.
- عدم تعديل مركز الإدارة أو إدارة المستخدمين أو الصلاحيات أو قواعد Supabase الحالية.

الملفات في هذه الحزمة:
1) index.html
2) rasheed-arabic-logo.png
3) assets/images/founder-samy.png
4) assets/images/arabic-classroom.png

مهم جدًا:
- لا تحذف ولا تستبدل assets/js/portal-login.js الموجود حاليًا في مشروع Rasheed Arabic.
- لا تستبدل login.html أو admin-hub.html أو student-accounts.html أو لوحات المستخدمين.
- index.html الجديدة تستدعي ملف الدخول الحالي: assets/js/portal-login.js
- لذلك تبقى المصادقة والتحويل إلى اللوحات حسب النظام الحالي، ويكون هذا التحديث للواجهة فقط.

طريقة الرفع:
- ارفع index.html إلى جذر مستودع rasheed-arabic واستبدل الصفحة الرئيسية القديمة.
- ارفع rasheed-arabic-logo.png إلى الجذر إذا لم يكن موجودًا، أو احتفظ بنسختك الحالية إذا كانت هي المعتمدة.
- ارفع مجلد assets/images مع الحفاظ على المسارات.

بعد الرفع اختبر بالترتيب:
- طالب: RA0004 أو البريد + كلمة المرور.
- معلم: البريد + كلمة المرور.
- ولي أمر: البريد + كلمة المرور.
- مدير: البريد + كلمة المرور.
- تأكد أن كل حساب ينتقل إلى لوحته الحالية.
